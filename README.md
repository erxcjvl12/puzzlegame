# 拼图游戏

一个使用 Java Swing 编写的桌面拼图游戏，包含登录、注册和 4×4 拼图玩法。项目图片资源存放在 `image` 目录中，游戏启动后从登录界面进入。

## 功能介绍

### 登录

- 输入用户名、密码和验证码后登录。
- 验证码由程序随机生成，点击验证码可以更换。
- 当前内置测试账号：

### 注册

- 输入账号、密码、再次确认密码和验证码。
- 检查账号、密码是否为空，两次密码是否一致，验证码是否正确，以及用户名是否已经存在。
- 注册成功后返回登录界面。

> 当前账号数据保存在程序运行期间的内存中，关闭程序后注册的账号不会保留。

### 拼图游戏

- 使用方向键移动空白格周围的拼图块。
- 点击“功能”菜单中的“重新游戏”可以重新打乱拼图。
- 按 `A` 键查看当前图片的完整预览。
- 按 `W` 键将拼图切换为完成状态，用于查看胜利界面。
- 移动步数会显示在游戏界面上。

### 图片分类

游戏图片资源分为以下类别：

- 美女：`image/girl/`
- 动物：`image/animal/`
- 运动：`image/sport/`

在游戏界面的“功能 → 更换图片”菜单中选择类别，再点击“开始游戏”切换到该类别的图片。
